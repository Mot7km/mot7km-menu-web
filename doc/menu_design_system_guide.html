FRONTEND ARCHITECTURE SPECIFICATION

دليل استخدامات وتوزيع ألوان المنيو للواجهات الأمامية

توثيق تقني دقيق موجه لمطوري الـ Frontend (React / Next.js / Flutter / Tailwind) يوضح بالتفصيل أين وكيف يُطبق كل لون في كافة مكونات وشاشات المنيو الرقمي.

قاعدة التنفيذ الأساسية للفرونت إند: ممنوع منعاً باتاً استخدام ألوان ثابتة كـ Hex codes داخل الكومبوننتس. يجب ربط كل عنصر بمتغير الـ CSS المناسب: var(--color-primary), var(--color-surface), var(--color-bg) وهكذا.

1 تفصيل كل لون واستخداماته الدقيقة في المنيو (Token Breakdown)

primary • لون هوية المتجر والتحفيز على الشراء (Action Hero)
Light: #FF6B00 Dark: #FF7A1A
خصائص الـ CSS:
background-color, color (للسعر), border-color (عند التحديد)
أين يُستخدم في الشاشة؟
1. أزرار الشراء الأساسية (Primary CTA): زر "+" للإضافة السريعة على كارت الطبق، وزر "أضف إلى السلة" الكبير.
2. زر إتمام الطلب / الدفع: الزر العائم في السلة (Checkout Button).
3. القسم النشط (Active Category Pill): خلفية التبويب المحدد حالياً في شريط الأقسام العلوي.
4. سعر الوجبة البارز: رقم السعر الرئيسي لجذب عين الزبون للقيمة.
5. خيارات التحديد النشطة: إطار ونقطة الاختيار (Radio / Checkbox) عند اختيار حجم الوجبة.
قاعدة للمطور:
لا تجعل كل شيء في الشاشة ملوناً بالـ primary حتى لا تفقد أزرار الشراء قوتها وجاذبيتها البصرية.
onPrimary • لون النصوص والأيقونات الواقعة فوق الـ Primary
Light: #FFFFFF Dark: #FFFFFF
خصائص الـ CSS:
color, fill / stroke للأيقونات
أين يُستخدم في الشاشة؟
1. نص وأيقونة زر "أضف للسلة" (مثل علامة + وكلمة أضف).
2. نص القسم النشط المكتوب داخل كبسولة الأقسام المفعلة.
3. نص وأيقونة زر المتابعة إلى الدفع في أسفل السلة.
قاعدة للمطور:
حرج جداً: لا تفترض أبداً أن لون النص فوق الزر أبيض ثابت (#FFF)! إذا اختار المطعم لون براند أصفر ليموني، الباك إند سيرسل onPrimary: #0F172A ليظل النص مقروءاً.
secondary • لون الهوية الثانوي والإجراءات المساندة
Light: #1E293B Dark: #334155
خصائص الـ CSS:
background-color, border-color
أين يُستخدم في الشاشة؟
1. الأزرار الثانوية (Secondary Actions): زر "تخصيص الوجبة" (Customize) بجانب زر الإضافة السريعة.
2. أزرار التراجع والإلغاء: مثل زر "إلغاء" أو "إغلاق النافذة المنبثقة".
3. هيدر المتجر وبطاقة معلومات الفرع: كخلفية لبطاقة الفرع (اسم المتجر، أوقات العمل، والتقييم).
4. بادج عداد السلة (Cart Badge): الدائرة العائمة التي تُظهر عدد السندوتشات المختارة فوق السلة.
onSecondary • لون النصوص والأيقونات الواقعة فوق الـ Secondary
Light: #FFFFFF Dark: #F8FAFC
خصائص الـ CSS:
color, fill
أين يُستخدم في الشاشة؟
نصوص وأيقونات الأزرار الثانوية، ورقم العداد الصغير داخل دائرة عداد السلة.
background • أرضية التطبيق الأساسية (The Canvas)
Light: #F8FAFC Dark: #0B0F19
خصائص الـ CSS:
background-color على مستوى <body> أو الحاوية الرئيسية
أين يُستخدم في الشاشة؟
أرضية صفحة المنيو بالكامل أثناء السكرول.
• في اللايت: رمادي هادئ ونظيف (Off-white) ليعطي كروت الأطباق البيضاء بروزاً ثلاثي الأبعاد.
• في الدارك: درجة ليلية عميقة فاخرة (Obsidian) تمنع إجهاد العين وتبرز صور الأطباق الملونة.
surface • أسطح الكروت والحاويات المرتفعة (Containers)
Light: #FFFFFF Dark: #151C2C
خصائص الـ CSS:
background-color للكروت والحاويات
أين يُستخدم في الشاشة؟
1. كروت الوجبات (Dish Cards): خلفية الكارت الذي يحتوي على الصورة، الاسم، والسعر.
2. نافذة تفاصيل الوجبة (Bottom Sheet Modal): خلفية النافذة المنبثقة لاختيار الحجم والمكونات.
3. كارت شريط السلة العائم: البار السفلي أو صفحة مراجعة الطلب والفاتورة.
4. خلفية البار العلوي (Sticky App Bar): عند تثبيت الهيدر أعلى الشاشة أثناء التمرير.
surfaceSubtle • الأسطح التفاعلية المدمجة داخل الكروت
Light: #F1F5F9 Dark: #1E293B
خصائص الـ CSS:
background-color للمدخلات والكبسولات
أين يُستخدم في الشاشة؟
1. حقل شريط البحث (Search Input): لكي يتمايز عن سطح الهيدر.
2. كبسولات الأقسام غير المحددة (Inactive Tabs): التبويبات التي لم يضغط عليها العميل بعد.
3. خلفية عداد الكمية [ - 1 + ]: الحاوية الصغيرة التي تجمع أزرار الزيادة والنقصان.
4. صندوق كتابة الملاحظات: Textarea لكتابة "ملاحظات إضافية للشيف" داخل تفاصيل الوجبة.
textPrimary • النصوص الأساسية عالية التباين (High Emphasis)
Light: #0F172A Dark: #F8FAFC
خصائص الـ CSS:
color على العناوين والأسماء
أين يُستخدم في الشاشة؟
1. اسم الوجبة: (مثال: "برجر ترافل بالمشروم").
2. عناوين الأقسام الرئيسية: (مثال: "الأطباق الرئيسية"، "المشروبات").
3. أسماء خيارات الإضافات والحجم: (مثال: "حجم عائلي كبير + 20 ر.س").
4. المجموع الكلي للفاتورة: الرقم النهائي في ملخص الدفع.
textSecondary • النصوص التوضيحية والبيانات الفرعية (Muted Text)
Light: #64748B Dark: #94A3B8
خصائص الـ CSS:
color للنصوص الثانوية
أين يُستخدم في الشاشة؟
1. وصف مكونات الوجبة: (مثال: "لحم أنجوس فاخر، شيدر معتق، صوص باربكيو").
2. السعرات الحرارية ومعلومات الحساسية: (مثال: "🔥 580 سعرة حرارية • يحتوي على الجلوتين").
3. نصوص التلميح (Placeholders): "ابحث عن طبقك المفضل..." داخل شريط البحث.
4. تفاصيل الفاتورة الفرعية: مثل رسوم الخدمة، الضريبة، والتوصيل.
border • الحدود والفواصل الدقيقة (Hairline Borders & Dividers)
Light: #E2E8F0 Dark: #1E293B
خصائص الـ CSS:
border-color, outline-color, border-bottom
أين يُستخدم في الشاشة؟
1. إطار كروت الوجبات (1px Border): يعطي الكارت تحديداً أنيقاً ويفصله عن الخلفية.
2. الفواصل الأفقية بين الخيارات (Dividers): الفاصل بين الإضافات في شيت تفاصيل الوجبة.
3. إطار خيارات الإضافات غير المحددة: إطار الراديو والـ Checkbox قبل الضغط عليه.
4. إطار حقل إدخال كود الخصم (Coupon Input Border): في صفحة السلة.
accent • شارات التميز والعروض الترويجية (Promotional Badges)
Light: #10B981 Dark: #34D399
خصائص الـ CSS:
background-color للبادجات، color للأيقونات والنصوص الترويجية
أين يُستخدم في الشاشة؟
1. شارة العروض والخصومات: البادج الصغير فوق زاوية صورة الوجبة (مثلاً: "وفر 25%").
2. شارات الأطباق المميزة: "الأكثر مبيعاً ⭐" (Best Seller)، أو طبق "جديد 🔥".
3. شطب السعر القديم: إبراز قيمة التوفير للزبون بجانب السعر الأصلي.

2 الألوان الوظيفية الثابتة في الفرونت إند (Functional Constants)

هذه الألوان لا يغيرها صاحب المطعم، بل يحتفظ بها الفرونت إند كثوابت قياسية لأنها ترتبط بالسلامة وسلوك المستخدم:

اللون الوظيفي الكود في اللايت الكود في الدارك الاستخدام في المنيو
Danger / Error #EF4444 #F87171 زر حذف وجبة من السلة، علامة الفلفل الحار (Spicy)، شارة "نفذت الكمية" (Sold Out)، أخطاء الكوبون.
Success #10B981 #34D399 إشعار "تم تطبيق كود الخصم بنجاح"، رسالة إتمام الطلب، شارة الوجبات النباتية (Vegan).
Warning #F59E0B #FBBF24 تنبيه "الكمية المتبقية محدودة (3 فقط!)"، تنبيهات وقت إغلاق المطبخ.
Shimmer / Loading rgba(0,0,0, 0.06) rgba(255,255,255, 0.08) هياكل التحميل العظمية (Skeleton Placeholders) أثناء جلب بيانات الوجبات.

3 كيفية تطبيق الألوان برمجياً في الـ CSS / Tailwind

/* عند استلام الـ JSON من الـ API، يقوم الفرونت إند بحقن القيم في :root */ :root { --color-primary: #FF6B00; --color-on-primary: #FFFFFF; --color-secondary: #1E293B; --color-on-secondary: #FFFFFF; --color-bg: #F8FAFC; --color-surface: #FFFFFF; --color-surface-subtle: #F1F5F9; --color-text-primary: #0F172A; --color-text-secondary: #64748B; --color-border: #E2E8F0; --color-accent: #10B981; } /* عند تفعيل الـ Dark Mode */ [data-theme="dark"] { --color-primary: #FF7A1A; --color-on-primary: #FFFFFF; --color-secondary: #334155; --color-on-secondary: #F8FAFC; --color-bg: #0B0F19; --color-surface: #151C2C; --color-surface-subtle: #1E293B; --color-text-primary: #F8FAFC; --color-text-secondary: #94A3B8; --color-border: #1E293B; --color-accent: #34D399; }
جاهز للربط مع Tailwind CSS: بمجرد تسمية الكلاسات مثل bg-[var(--color-surface)] أو text-[var(--color-primary)] يتحول المنيو بالكامل فوراً بين اللايت والدارك بسلاسة 100%.
